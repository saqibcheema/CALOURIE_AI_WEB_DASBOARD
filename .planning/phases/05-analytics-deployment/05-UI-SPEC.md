## Design System

| Property | Value |
|----------|-------|

## Component Specifications

### 1. Analytics Page (`/dashboard/analytics`)

**Layout:**
```
┌─────────────────────────────────────────────┐
│ Page header: "Analytics" h1 + subheading    │
├────────┬────────┬────────┬────────┐         │
│ Stat   │ Stat   │ Stat   │ Stat   │ ← 4 cards in lg:grid-cols-4
│ Card   │ Card   │ Card   │ Card   │
├───────────────────────────────────┘
│ Chart card (white, rounded-card, shadow)    │
│   ┌─ Section label "7-Day Trend"            │
│   ├─ [Meals Logged][AI Vision][Barcode][Devices] ← tabs
│   └─ Recharts BarChart 250px tall           │
└─────────────────────────────────────────────┘
```

**Page wrapper:** `div.space-y-6.p-6.bg-slate-50.min-h-screen` — matches Overview page exactly.

**Stat cards grid:** `div.grid.grid-cols-1.md:grid-cols-2.lg:grid-cols-4.gap-6` — reuse `StatCard` component.

**Chart card wrapper:** `div.bg-white.rounded-[10px].shadow-[0_1px_3px_rgba(15,23,42,0.06),0_1px_2px_rgba(15,23,42,0.04)].p-6`

### 2. Metric Selector Tabs

**Tab strip:** `div.flex.gap-1.mb-6` positioned below the section label "7-Day Trend".

**Individual tab:**
- Inactive: `button.px-3.py-1.rounded-[7px].text-sm.font-medium.text-slate-400.hover:text-slate-600.hover:bg-slate-100.transition-colors`
- Active: `button.px-3.py-1.rounded-[7px].text-sm.font-medium.text-arctic-600.bg-arctic-50`

**Tab labels (exact copy):**
| Tab | dataKey |
|-----|---------|
| Meals Logged | `meals_logged` |
| AI Vision | `vision_uses` |
| Barcode Scans | `barcode_scans` |
| Unique Devices | `unique_devices` |

### 3. Bar Chart (`BarChart` from Recharts)

**Container height:** `h-[250px]` (fixed via `className` on wrapper div).

**Recharts config:**
```tsx
<ResponsiveContainer width="100%" height="100%">
  <BarChart data={trend} margin={{ top: 8, right: 16, left: 0, bottom: 0 }}>
    <XAxis dataKey="day" tick={{ fontSize: 11, fill: '#94a3b8' }} axisLine={false} tickLine={false} />
    <YAxis tick={{ fontSize: 11, fill: '#94a3b8' }} axisLine={false} tickLine={false} width={40} />
    <Tooltip
      contentStyle={{ borderRadius: '7px', border: '1px solid #e2e8f0', fontSize: 12 }}
      cursor={{ fill: '#f0f9ff' }}
    />
    <Bar dataKey={activeMetric} fill="#0ea5e9" radius={[4, 4, 0, 0]} />
  </BarChart>
</ResponsiveContainer>
```

**Bar radius:** top corners rounded `[4, 4, 0, 0]` for a modern pill-top look.

### 4. Stat Cards (Analytics Page)

Reuse `StatCard` component unchanged. Props per metric:

| Title | Icon | Trend direction |
|-------|------|-----------------|
| Total Meals Logged | `IconSalad` | computed: today vs 7 days ago |
| AI Vision Uses | `IconEye` | computed |
| Barcode Scans | `IconBarcode` | computed |
| Unique Devices | `IconDevices` | computed |

### 5. Overview Page Update (`/dashboard/page.tsx`)

**No layout changes** — only data source changes. Remove `MOCK_STATS` and `MOCK_TREND_DATA` constants. Replace with `useEffect` fetch. All visual classes remain identical.

**Loading skeleton:** Replace the entire stat cards section and chart section with pulse skeletons:
- Stat card skeleton: `div.bg-white.rounded-[10px].h-[120px].animate-pulse` (4 of these in same grid)
- Chart skeleton: `div.bg-white.rounded-[10px].h-[160px].animate-pulse`

### 6. Error State

Shared pattern for both Overview and Analytics pages:

```tsx
<div className="rounded-[10px] bg-red-50 border border-red-200 p-4 flex items-center gap-3">
  <IconAlertCircle size={20} className="text-red-500 shrink-0" />
  <div className="flex-1">
    <p className="text-sm font-medium text-red-700">Failed to load analytics data</p>
    <p className="text-xs text-red-500 mt-0.5">Check your connection and try again</p>
  </div>
  <button onClick={refetch} className="text-xs text-red-600 underline font-medium">Retry</button>
</div>
```

### 7. Empty / Zero State

When all values in `today` are 0 (no data for today yet):
- Still show stat cards with `0` values — do NOT show an empty state UI
- Show bar chart with zero-height bars — this is valid data (app not opened today)
- No empty state needed for zero data

## Interaction Contracts

| Interaction | Behavior |
|-------------|----------|
| Tab click | Immediately switches `activeMetric` state; bar chart re-renders with new dataKey; no loading state |
| Chart tooltip hover | Recharts tooltip shows: day name + metric value; styled with rounded-[7px] border |
| Page load | Fetch fires once on mount; shows skeleton until data arrives |
| Fetch error | Shows error banner; hides skeleton; Retry re-fires fetch |
| Trend % overflow | If prior day value is 0 (division by zero): show "N/A" instead of Infinity% |

---

## Animation & Motion

| Element | Motion |
|---------|--------|
| Bar chart initial render | `isAnimationActive={true}` (default Recharts) — subtle grow-from-bottom on load |
| Tab switch | No animation — immediate state swap |
| Skeleton → content | No fade; skeleton disappears when `!loading` |
| SparklineChart (Overview) | `isAnimationActive={false}` (already set in component) |
